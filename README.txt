MICROAPP AGENDA CSIU XI

Publicación rápida:
1. Netlify Drop: abre https://app.netlify.com/drop y arrastra la carpeta completa o el contenido del ZIP extraído.
2. GitHub Pages: crea un repositorio, sube todos los archivos, activa Settings > Pages > Deploy from branch.
3. Cloudflare Pages: crea un proyecto Pages y carga estos archivos mediante Git.

No requiere base de datos. Para actualizar la agenda, modifica data.js o vuelve a generar desde el Excel.
